    Morning brief and time zone

    To change them, set CHIEF_BRIEF_HOUR (0 to 23, or off) and CHIEF_TIMEZONE in .env, then restart Chief. Chief reads them when it starts, so they aren't saved from this page.

    Keys in .env

    Keys stay in the .env file on the computer running Chief. This page shows only whether each is set, never its value, and never asks you for one.
