# data/

`demo_cache.json` (and its `.bak`) is generated by `python -m chief record-demo`. It holds the results of the demo's read calls
(calendar events, email snippets, web results) from the test account, so the demo can answer when the network is down.
It is git-ignored: do not commit it. See [docs/demo-day.md](../docs/demo-day.md).

`sleep.csv` (if you add one) is the optional sleep export read by live mode (`CHIEF_HEALTH_CSV`).
